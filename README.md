# 演示库

单管理员 HTML PPT 管理系统：管理演示稿、设置私有或链接分享，所有 PPT 共用一套播放器。

## 启动

需要 Node.js 22.13 或以上。

```sh
npm ci       # 首次安装依赖
npm start    # 自动构建并启动
```

打开 http://127.0.0.1:4173/。首次运行设置管理员；以后使用已有账号。现有账号、PPT 和分享链接保存在 `data/`，重启不会重置。

## 目录怎么找

日常开发主要看前三个目录：

| 目录             | 负责什么                                                 | 常用入口                                                  |
| ---------------- | -------------------------------------------------------- | --------------------------------------------------------- |
| `frontend/`      | 管理界面、编辑器、全站共用的播放器                       | `app.js`、`editor.js`、`settings.js`、`player/runtime.js` |
| `server/`        | 接口、账号权限、分享、数据保存                           | `app.mjs`、`auth.mjs`、`security.mjs`、`store.mjs`        |
| `presentations/` | 内置 PPT 的源稿、样式、素材                              | `areal/deck.mjs`、`areal/slides/`、`areal/styles/`        |
| `scripts/`       | 构建内容包与图标、手动同步源稿、清理检查结果             | `build.mjs`                                               |
| `tests/`         | 后台接口与浏览器回归检查                                 | `*.test.mjs`、`*browser.mjs`                              |
| `outputs/`       | 给使用者看的说明                                         | `演示库使用说明.md`                                       |
| `data/`          | **真实账号、PPT 内容版本、图片、权限与分享链接，请保留** | 由后台管理，无需手改                                      |
| `work/`          | 自动生成的内容包、图标和测试产物                         | 构建产物在 `build/`；检查产物在 `qa/`                     |
| `node_modules/`  | 安装的依赖                                               | 由 `npm ci` 生成，无需手改                                |

根目录的 `package.json` 定义运行命令；`package-lock.json` 固定依赖版本；`.env.example` 是配置示例；其余点开头的文件是忽略和格式化规则。

```text
浏览器
  └─ frontend/ ── /api/ ── server/ ── data/
        └─ player/ 统一管理翻页、激光笔、批注、目录和备注

presentations/areal/ ── 构建 ── work/build/presentations/areal/
                                  └─ 首次运行时导入 data/
```

## 改功能 / 改 PPT 分别改哪里

- 管理界面：`frontend/app.js` 和 `frontend/app.css`。
- 编辑器入口与源码模式：`frontend/editor.js`；可视化编辑：`frontend/editor/visual.js`（界面）、`canvas.js`（选中、拖拽、文字、历史）、`document.js`（隔离画布与内容处理）、`thumbnails.js`（共享缩略图）、`menu.js`（右键菜单）、`shapes.js`（形状与链接校验）、`visual.css`。
- 网站与安全设置：`frontend/settings.js`；自定义下拉菜单：`frontend/components/select.js`；图标处理：`frontend/branding.js`。
- 演示控件、翻页和画笔：`frontend/player/`，所有 PPT 共用。
- 新建演示的内置模板：`frontend/templates/catalog.js`，提供空白、简洁汇报、技术分享、项目复盘；每份模板生成独立的 HTML、CSS 与备注，可直接在可视化编辑器修改。
- 登录和权限：`server/auth.mjs`；通行密钥与双因素验证：`server/security.mjs`；网站设置和 slug 校验：`server/settings.mjs`；HTTP 接口：`server/app.mjs`；保存和分享：`server/store.mjs`；内容解析与校验：`server/content.mjs`。
- **日常修改或新增 PPT：直接在网页中操作**，保存到 `data/`，无需修改项目源码。
- 内置 AReaL 源稿：`presentations/areal/`。`metadata.json` 管名称和尺寸，`deck.mjs` 与 `slides/` 管页面内容，`styles/` 管样式，`assets/` 管原始图片和论文图。

PPT 只包含页面、样式、备注和素材。播放器将它装入隔离的 iframe，页面不运行自己的脚本。素材和内容必须经过后台权限检查；私有 PPT 不会通过静态文件路径公开。

`presentations/` 是内置源稿，`data/` 是网页正在使用的版本。普通构建和启动**不会覆盖**网页里已经修改的 PPT。如果你明确要用源稿更新现有 AReaL 内容，先在网页导出备份，再执行：

```sh
npm run sync:areal
```

该命令覆盖 AReaL 的内容和素材，保留权限与分享设置。新增 PPT 通常使用网页的新建或导入功能，无需复制 AReaL 源码目录。

## 检查和清理

```sh
npm run dev           # 后台变动时重启
npm run build         # 只重新生成 work/build，不写真实数据
npm test              # 接口和浏览器检查，使用独立测试数据
npm run format:check  # 检查代码格式
npm run clean:qa      # 删除 work/qa 中的测试截图等
```

浏览器测试默认使用 macOS 上已安装的 Chrome，也可设置 `CHROME_PATH` 或执行 `npx playwright install chromium`。`work/` 可在停止服务后删除，下次 `npm start` 会重建必要内容。`data/` 不属于临时文件；备份时停止服务并复制整个目录。

## 部署给其他人访问

当前地址只供本机使用。部署到服务器后，复制 `.env.example` 为 `.env`，配置 HTTPS 域名：

```dotenv
HOST=0.0.0.0
PORT=4173
PUBLIC_URL=https://slides.example.com
```

反向代理保留原始 `Host`。配置 HTTPS 后，会话 Cookie 自动启用 `Secure`。首次远程初始化可设置 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`（至少 10 个字符），初始化后移除配置中的密码；已有管理员时不会重设账号。

素材来源见 `presentations/areal/assets/README.md`。Lucide 和 KaTeX 的许可保留在依赖包与生成文件中。

## 网站设置、图标与地址

点击侧栏账号后，仅右侧主内容切换为设置，原有演示库侧栏和地址保持不变。设置区域内采用左侧分类卡片、右侧设置卡片；点击「文稿」或「模板」可直接切回相应内容。基础设置管理网站名称和默认图标；安全设置管理密码、通行密钥和双因素身份验证。图标上传后转为 128 × 128 PNG。

每份 PPT 在卡片的「更多 → 演示稿设置」或编辑器右上角设置按钮中配置图标与 slug。演示地址为 `/present/<slug>`，编辑地址为 `/edit/<slug>`；修改 slug 不改变数据库编号、素材目录或批注归属。未单独设置图标时，使用网站图标。

分享时可自定义 slug，完整地址为 `/s/<slug>/<随机访问凭证>`。每条链接可以单独修改 slug、设置有效期或撤销。旧版 `/s/<随机访问凭证>` 地址继续遵守原链接的权限和有效期；修改 slug 不等于撤销访问凭证。

## 账号安全

- 通行密钥使用 [SimpleWebAuthn](https://simplewebauthn.dev/docs/packages/server)，验证来源、挑战、签名和设备用户验证。登录后添加通行密钥直接调用设备验证；删除等敏感操作仍需输入当前密码，已启用双因素验证时还需动态验证码或恢复码。
- 通行密钥在 `localhost` 或 HTTPS 域名上使用。本机可访问 `http://localhost:4173/`；`127.0.0.1` 和 `localhost` 的登录 Cookie 分开保存，需要在新地址登录。各域名的通行密钥独立绑定。
- 双因素验证使用 [OTPAuth](https://github.com/hectorm/otpauth) 的 TOTP。验证器扫码后需输入验证码才会启用，密码或通行密钥登录都需要完成第二步验证。相同动态码不能重复使用。
- 启用后生成 10 个一次性恢复码，可复制或下载。验证码密钥在数据库中加密保存，恢复码只保存哈希；`data/security.key` 是本机加密密钥，备份时务必与整个 `data/` 一起保存。
- 功能已接入，但不会替管理员自动启用双因素验证、添加通行密钥或改变密码。

安全回归在独立测试数据中执行，浏览器通过虚拟验证器执行真实 WebAuthn 注册和登录流程，不使用用户的设备密钥。

## 可视化编辑器

编辑页默认使用左侧页面列表、中间画布、右侧属性、画布上方页面名称、底部备注的布局。支持多行文本框双击编辑、元素拖动/缩放、文字/图片/12 种形状插入、超链接、复制删除、字号/颜色/对齐、页面增删复制排序、备注和撤销重做。页面列表和画布右键菜单提供各自的操作，列表不再显示独立标题栏与底部操作栏。源码模式提供全宽 HTML、CSS、备注 JSON 与素材管理，查看演示通过顶栏「演示」打开。

底部区域可直接编辑当前页备注和参考资料；参考资料包含名称与 HTTP(S) 链接，支持新增和删除，并随页面排序、复制及撤销历史同步移动。已登录管理员在播放器 Dock 中可点击「编辑当前页」，直接打开对应演示稿与当前页；游客和未登录分享访问不显示该按钮。

编辑器沿用 HTML/CSS 内容，不将现有幻灯片转换为另一种画布格式。控制器从父页面操作不允许脚本运行的同源沙箱，画布选框位于幻灯片外；保存时移除临时编辑状态，继续使用原内容接口、版本冲突检查和服务端清洗。历史记录保留在当前可视化编辑会话中；从源码重新载入画布会重置这段撤销历史。拖动以 CSS 独立位移保留已有 `transform`，按画布缩放比例换算坐标；任意导入 HTML 的嵌套旋转或缩放布局尚不保证精确拖拽。

公式支持双击编辑 LaTeX、实时预览及插入；SVG 作为整体操作。拖动支持边缘与中心吸附辅助线，按住 Alt 可临时暂停吸附。多人协同、SVG 内部节点编辑和组合拆组不在当前版本内。图中的文字若属于位图，则只能更换图片或叠加文本。页面排序会同步移动备注/参考资料，但不会重写稿件里手写的页码文字。元素尺寸修改仍遵守原来的 HTML 布局，因此复杂网格或弹性容器可能影响相邻元素。

实现依据浏览器原生 [contenteditable](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/contenteditable) 和 [translate](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/translate)。新增 `tests/visual-editor-browser.mjs` 在独立数据中验证改字、缩放坐标拖拽、缩放、历史、图片上传、页面/备注同步、源码往返、保存重开、演示结果及 AReaL 原稿完整性。

缩略图采用与列表视口等高的共享沙箱文档，CSS 与字体只加载一次，只挂载可见页和邻近页，离屏内容按稳定页面 ID 缓存；滚动沿用缓存位置，页面内容在空闲时间分批准备。列表仅显示页码与缩略图，完整标题仍用于无障碍名称。编辑历史共享未改变的页面快照，修改时只序列化当前页，切换页面不会复制整稿。

编辑画布支持滚轮上下翻页，文字编辑、可滚动组件、备注和侧栏保留各自的操作。播放器和画布共用 `frontend/components/wheel-navigation.js`，在限制翻页频率的同时允许连续滚动；播放器提前准备相邻页，备注和菜单只在打开时更新，普通区域的连续点击不会被当作图片双击而忽略。

新超链接保存在元素的 `data-editor-href` 中，由统一播放器响应普通指针点击和 Enter；已有原生 `<a>` 链接可直接修改。编辑器和播放器都限制为 HTTP(S)、mailto、tel，网页在新标签页打开并隔离 opener。内容包继续只存储内容及元数据，链接激活不需要 PPT 自带脚本。

编辑器的通用样式面板包含填充、边框颜色/宽度/线型、字号/字色及文字样式。新增形状的边框沿 SVG 轮廓绘制；普通组件使用 CSS 边框，SVG 图表的字色与字号作用于文本节点，保留图表几何。数字控件保留键盘步进及范围验证，隐藏原生箭头并使用 Lucide 按钮。自定义颜色面板包含主题/标准色、HSV 色板、Hex 输入、透明和本机最近 10 色；屏幕取色使用 [EyeDropper API](https://developer.mozilla.org/en-US/docs/Web/API/EyeDropper/open)，浏览器不支持时禁用该按钮。

侧栏和底部备注栏可通过分隔线拖拽或键盘调整，本机记住尺寸。保存采用约 1 秒防抖与串行请求；在输入中的文字通过克隆快照保存，不改变光标和焦点。保存期间产生的改动随后继续写入；网络失败退避重试，版本冲突不盲目覆盖。顶栏只显示状态图标。名称、作者、简介统一在演示稿设置中修改，打开设置前会先完成待保存内容，避免版本竞争。首屏和稿件加载均有动画与骨架屏，并遵循减少动态效果的系统偏好。

`tests/editor-workspace-browser.mjs` 在独立数据中验证通用样式、形状轮廓、自定义颜色、输入中自动保存及失败重试、三栏尺寸持久化、延迟加载和元数据保存。取色器在无界面测试中仅验证 API 接线，系统取色窗口需浏览器支持并由用户实际选择。

页面标题直接在画布上方的标题栏编辑，底部仅保留备注。拖拽左侧缩略图可调整页面顺序，插入位置有横线提示，靠近列表边缘会自动滚动；备注随页移动，操作支持撤销。设置 → 基础设置提供浅色、深色、跟随系统三种主题，主题只改变管理界面，不改变稿件内容。

编辑器内部离开链接与浏览器后退使用自定义保存确认框。浏览器刷新/关闭不能显示网页自定义确认框，因此通过本机草稿恢复承接：重新进入时选择恢复或使用服务器版本。服务端版本冲突仍需人工处理；本机浏览器存储不可用时不保证草稿恢复。

## 文稿、模板与 PowerPoint 导入

侧栏使用「文稿 / 模板 / 回收站」。文稿列表在搜索框旁通过自定义下拉框筛选全部、私有、链接分享。模板库内置简洁汇报、技术分享、项目复盘三套可编辑模板；可以新建、编辑、复制、导出、移至回收站，也可以从文稿卡片菜单「另存为模板」。使用模板新建时复制 HTML、CSS、备注、尺寸与素材，之后双方独立修改。

模板复用现有编辑器与内容接口，用数据库 `kind` 区分；模板仅管理员可访问，不能生成分享链接。首次升级自动加入内置模板，之后重启不会覆盖修改或重新加入已回收的模板。数据仍保存在各自的 `data/decks/<id>/`。模板预览通过已登录的演示播放器打开。

点击「导入」支持 `.pptx`、`.ppt`、HTML、ZIP 内容包和旧版 `.deck.json`，PowerPoint 有两种模式：

- **文稿**：按原顺序导入全部幻灯片及备注，保留文字、图片、常见形状、表格、主题颜色、背景及占位符继承。
- **模板**：读取每个幻灯片母版关联的版式，继承母版背景、公共元素和占位符样式，生成可编辑的版式页面。

卡片点击进入编辑，「演示」按钮在新标签页打开播放器。卡片菜单和编辑页顶栏的「导出」可选择 ZIP、PDF 和 PowerPoint（`.pptx`）；从编辑页导出前会先保存当前修改，保存失败时不会导出旧版本。PDF 通过 Chromium 保留 HTML 文字和矢量图形；PPTX 用高清页面图片保持版式，附带可编辑的讲稿备注，不提供页面内部组件的原生编辑。PDF/PPTX 导出前安装 `npx playwright install chromium`（Linux 可加 `--with-deps`）；可通过 `EXPORT_CHROMIUM_PATH` 指定兼容的 Chromium 可执行文件。渲染仅使用当前稿件本地素材，禁用脚本和外部网络请求，一次只生成一个文件，单次上限为 120 秒。实现位于 `server/render-export.mjs`。

ZIP 内容包包含 `metadata.json`、`content.html`、`styles.css`、`notes.json`、可选的 `favicon.png` 和 `assets/` 素材目录。图片与字体以独立文件保存，导出采用流式压缩。重新导入会创建独立的私有文稿或模板，保留作者、尺寸、备注、图标和素材，不恢复原分享链接。ZIP 内容包上传上限为 200 MB，解压后总大小上限为 256 MB；旧版 JSON 内容包仍可导入。实现位于 `server/package.mjs`，共用压缩包校验在 `server/archive.mjs`。

PowerPoint 导入入口在 `frontend/library/import.js`；`server/import/` 负责 ZIP/XML 读取、OOXML 转换和工作线程。现代 `.pptx` 无需额外系统依赖。旧版二进制 `.ppt` 需要服务器安装 LibreOffice，默认调用 PATH 中的 `soffice`，可用 `SOFFICE_PATH` 指定可执行文件；缺少时会提示先另存为 `.pptx`。反向代理请求体限制应至少 200 MB，以支持 ZIP 内容包上传；PowerPoint 文件上限为 40 MB。

导入不是 PowerPoint 排版引擎：常见元素保留为 HTML/SVG，字体由浏览器本机字体替代。普通柱形图转 SVG；复杂图表保留缓存数据为可编辑表格。SmartArt、嵌入对象、音视频、EMF/WMF、动画和特殊形状存在转换限制，导入结果会列出检测到的未保留或简化项目。原生 Office 数学对象暂不转换，可在编辑器中重建公式。母版提取仅包含真实母版及版式，直接画在某一张幻灯片上的装饰不会自动变成母版。

解析在独立工作线程中执行，不运行文稿脚本或宏、不下载 OOXML 外部链接素材；压缩包大小、解压体积、素材数量和解析时间均有限制。导入失败会回滚新建条目及素材。`tests/powerpoint-templates.test.mjs` 检查转换、主题继承、富文本序列化、模板修改持久化、素材独立复制、分享限制及鉴权；测试使用合成 OOXML fixture 和隔离数据。

## 演示计时与提示位置

播放器底部工具栏设有独立计时区，直接显示总用时、本页用时、开始/暂停及重置按钮。重置需要再次点击确认；点击时间查看逐页统计。正在计时时，工具栏会在空闲后原位收缩为只显示总用时的小条，鼠标移近时平滑展开；暂停后随工具栏一起隐藏。窄屏时计时区排在工具栏上方。计时按稳定页面 ID 累加用时、记录访问次数，支持二次确认后重置。使用单调时钟计算，不依赖定时器触发精度；记录保存在当前浏览器，刷新后以暂停状态恢复，切到后台自动暂停。`frontend/player/timing.js` 管理累计规则，`timer.js`/`timer.css` 管理控件。

基础设置中的「提示位置」支持六个位置和即时预览，配置保存在网站设置中。管理页、编辑器和播放器共用 `components/toast.js`/`toast.css`，使用 manual popover 进入顶层，弹窗打开时重新提升提示层级。

## 工作区、品牌素材、观众互动与备份

账户已扩展为工作区成员：所有者负责网站、安全、成员和备份；编辑者可以制作、分享与演示内容；审阅者和查看者使用只读模式。旧版单管理员数据会自动迁移为工作区所有者，原账号、密码、通行密钥和双因素验证保持有效。

设置中的「品牌与素材」保存品牌主色、辅助色、字体名称及最多 200 个图片素材。品牌素材存放在 `data/brand-assets/`，编辑器工具栏可直接打开素材库；插入时复制到当前文稿的素材目录，之后删除品牌库原件不会影响已经制作的页面。

演讲者视图可以开启观众互动，会生成二维码和公开互动地址。观众无需登录即可匿名提问、参与当前投票和提交 1–5 分反馈；演讲者面板实时汇总问题、票数和平均评分，可以标记已回答的问题或结束投票。互动会话由演讲者主动创建，关闭演讲者页面后结束。

「备份中心」可以生成、下载、删除和恢复整站 ZIP 备份。备份包含 SQLite 数据库、全部文稿版本、素材、品牌资源和安全密钥，保存在 `data/backups/`。恢复会替换现有数据并让容器自动重启，操作前应先创建一份当前数据备份。
