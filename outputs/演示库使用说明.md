# 演示库

打开：<http://127.0.0.1:4173/>

首次安装时设置管理员账号和密码，以后使用已有账号。原来的 27 页「实习分享 · 后训练与 AReaL」已迁入；权限以网页中的设置为准。

- **演示**：点击卡片上的「演示」，在新标签页中打开，当前演示库保持不变。统一支持翻页、激光笔、批注、目录、备注、全屏和打印。双击内容图片打开全屏灯箱，单击图片切换缩放，滚轮连续缩放，放大后可拖动查看；Esc 关闭。
- **编辑**：点击文稿卡片进入编辑器，默认显示可视化画布，双击文字修改，拖动元素移动位置，拖动选框角点调整尺寸；右侧修改字号、颜色和对齐，画布上方修改页面名称，底部填写备注。顶部可插入文字、图片、形状和链接。HTML、CSS 在「源码」中修改；名称、作者、简介在右上角「演示稿设置」中修改。
- **文稿**：侧栏进入文稿列表，搜索框旁的下拉框可选择全部、私有、链接分享。
- **模板**：内置简洁汇报、技术分享、项目复盘三套模板，均可编辑；也可新建模板，或在文稿菜单中选择「另存为模板」。点击「使用模板」创建一份独立文稿，后续编辑互不影响。
- **新建 / 导入**：新建时可选择模板库中的任一模板。导入支持 `.pptx`、`.ppt`、HTML 和系统导出的 ZIP 内容包，也兼容旧版 `.deck.json`。上传 PowerPoint 后选择「文稿 · 导入全部幻灯片」或「模板 · 提取母版和版式」。
- **导出**：卡片菜单和编辑页顶栏的「导出」可选择 ZIP、PDF、PowerPoint（.pptx）。编辑页导出会先保存当前修改。PDF 保留页面版式，便于阅读和打印；PPTX 将各页保存为高清图片并附带备注，页面内部文字和图形不能直接在 PowerPoint 中拆分编辑。ZIP 将页面 HTML、样式、元数据、备注和图片、字体分文件保存。重新导入后得到独立的私有文稿或模板，可继续编辑；原分享链接不会随包导入。ZIP 文件上限为 200 MB，解压后上限为 256 MB。
- **分享**：点击卡片上的链接图标，将权限切换为「链接分享」，选择有效期及是否开放备注，再生成并复制链接。
- **撤销**：可以单独撤销链接；改为「私有」会让所有旧链接失效。回收站恢复的 PPT 也默认为私有。

现在运行的是本机服务。要让其他人通过互联网访问，需要部署到服务器并配置 HTTPS 域名；项目 README 和 `.env.example` 已说明配置方式。

重启服务：在项目目录运行 `npm start`。

每份 PPT 的内容、备注和素材独立保存；控件由系统统一管理。真实运行数据保存在项目的 `data/`，请保留并定期备份。

演示左上角提供计时器，点击播放开始、暂停按钮暂停，点击时间查看每页累计用时和访问次数。回到同一页会继续累加，重置需再次确认。记录保存在当前浏览器，刷新后保留并暂停；切换到后台会自动暂停，返回后点击开始继续。

## 项目文件怎么找

| 目录                     | 内容                                               |
| ------------------------ | -------------------------------------------------- |
| `frontend/`              | 管理界面、编辑器和统一演示控件                     |
| `server/`                | 登录、权限、分享链接和数据保存                     |
| `presentations/`         | 内置 AReaL 的源稿与图片                            |
| `data/`                  | 实际使用的 PPT、账号与分享设置，不能当临时文件删除 |
| `scripts/`、`tests/`     | 构建和检查工具                                     |
| `work/`、`node_modules/` | 自动生成的内容和依赖                               |
| `outputs/`               | 本使用说明                                         |

完整开发入口和命令见项目根目录的 `README.md`。日常管理 PPT 在网页中完成即可。旧版独立 HTML 已移除，统一使用演示库入口。

## 设置、图标和自定义地址

- 点击左侧账号（如 `admin`）后，演示库侧栏保留，右侧主内容显示设置；在设置区域切换基础 / 安全分类。点击「文稿」或「模板」即可切回内容列表。基础设置可选择 Toast 提示的六种弹出位置并预览，提示显示在弹窗上方。设置中可修改网站名称、网站图标或密码，管理通行密钥和双因素身份验证。
- PPT 卡片的「更多 → 演示稿设置」或编辑器右上角的设置按钮，可修改这份 PPT 的名称、作者、简介、图标和 URL 名称（slug）。未上传图标时，沿用网站图标。
- 分享对话框可设置分享 URL 名称；已有链接旁的编辑按钮可修改它。分享地址包含自定义名称和随机访问凭证。需要停止访问时，请撤销链接。
- 通行密钥请在 `http://localhost:4173/` 或部署后的 HTTPS 域名下配置。切换到 localhost 后需要重新登录。
- 启用双因素验证时，用验证器扫描二维码并填写验证码，再妥善保存一次性恢复码。之后使用密码或通行密钥登录，都需要第二步验证。

自定义下拉菜单支持鼠标、方向键、Enter 确认和 Esc 关闭。

## 可视化编辑

左侧缩略图切换页面，右键缩略图可新增、复制、上移、下移或删除页面。右键画布空白处可插入内容、管理当前页；右键元素可改字、设置链接、复制或删除。页面调整会同时调整对应备注与参考资料的位置。页面名称在画布上方的标题栏直接编辑，底部仅显示备注。左侧缩略图可以拖拽排序，横线提示插入位置。

在主要画布区域向下滚动切换下一页，向上滚动切换上一页；正在编辑文字时不会翻页，备注与侧栏仍可正常滚动。缩略图列表只显示页码和页面图像。

- 单击选中元素；双击普通文字或点击右侧「编辑文字」后输入。文本框可换行，退出编辑后仍可再次双击修改。
- 「形状」提供矩形、圆角矩形、椭圆、三角形、菱形、六边形、星形、左右箭头、燕尾箭头、对话框和直线。
- 选中元素后点「链接」或按 `⌘/Ctrl + K` 添加、修改或移除超链接。支持网页、邮件和电话地址；演示时使用普通指针点击，网页在新标签页打开。
- 拖动移动；拖动选框四角缩放，图片与 SVG 按比例缩放。右侧也可输入位置和尺寸。
- 右侧「选择父组件」可选择文字所属容器，再通过位置和尺寸调整整组内容。
- 顶部撤销 / 重做；支持 `⌘/Ctrl + Z`、`⌘/Ctrl + Shift + Z`。选中元素后，方向键微调，Shift 加方向键每次移动 10 像素，Delete 删除，`⌘/Ctrl + D` 复制。
- 编辑暂停约 1 秒后自动保存，文字输入不会失焦。顶栏用小圆点表示待保存、旋转图标表示保存中、勾号表示已保存；悬停查看状态，失败时点击重试。也可点击「保存」或使用 `⌘/Ctrl + S` 立即保存。
- 每种组件都能设置填充、边框颜色/粗细/样式，以及文字颜色/字号/粗体/斜体/下划线/删除线和对齐。图片中的像素文字仍需更换图片后才能改变。
- 颜色面板提供主题色、标准色、自定义色板、十六进制输入、无颜色和最近使用颜色。支持屏幕取色的浏览器可点击取色器；Chrome / Edge 请使用本机地址或 HTTPS。
- 拖动左侧栏、右侧栏和底部备注栏的分隔线可调整大小；尺寸在本机浏览器保留。双击分隔线恢复默认，也可聚焦分隔线后用方向键调整。

公式支持双击编辑 LaTeX，实时查看效果；顶部「公式」可插入新公式。拖动元素时显示边缘、中心对齐辅助线并自动吸附，按住 Alt 可暂时关闭吸附。SVG 图表和图片作为整体移动或缩放，SVG 内部节点和复杂布局结构在「源码」里编辑；暂不支持多人同时编辑、任意组合拆组。导入 HTML 的文字若已合成在图片中，也无法直接改字。可视化与源码共用同一份 HTML/CSS，不需要迁移已有 PPT。

在「设置 → 基础设置 → 外观」中选择浅色、深色或跟随系统，保存后生效。演示稿自身的配色不会随网站主题改变。

未保存时返回演示库或使用浏览器后退，会显示自定义确认框。刷新、关闭浏览器时由本机草稿保留尚未同步的内容；重新进入编辑器可选择恢复草稿。源码视图保留 HTML、CSS、备注 JSON 与素材管理，演示请使用顶栏「演示」。

## PowerPoint 导入说明

导入的文字、图片、常见形状和表格可以继续在可视化编辑器中修改。母版导入生成一组版式页面，保留母版中的背景、公共元素与占位符；它不会把每张幻灯片的实际内容当作母版。

复杂图表、SmartArt、嵌入对象、音视频、特殊字体和动画不能保证完整还原，检测到的转换限制会在导入完成时列出。普通柱形图保留为 SVG，复杂图表保留为数据表；公式可以用编辑器的 LaTeX 功能重建。导入后建议检查版式和换行。

文件上限为 40 MB。`.pptx` 可直接导入；旧版 `.ppt` 需要服务端安装 LibreOffice，当前本机已具备。部署时未安装的，可先在 PowerPoint 中另存为 `.pptx` 再导入。
